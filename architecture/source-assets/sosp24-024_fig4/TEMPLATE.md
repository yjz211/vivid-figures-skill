# VA-103 · 候选计划筛选与全局执行落地

问题结构与资源规格共同生成候选计划，经局部权衡、跨计划资源协调及状态转换，最后映射成执行操作。小散点、占用条和代码片段分别解释筛选、资源使用与执行方式。

![资产预览](preview.png)

## 适用范围

- 局部候选筛选后还需全局资源协调的优化流程
- 从问题模型与资源约束生成执行计划及代码的系统

不适合：没有实际候选比较、只有一条确定计算路线；无法说明内部小图含义的通用研究流程。

## 阅读顺序

1. 从左侧模型与资源规格进入绿色候选计划区。
2. 向右读红色局部权衡，区分保留与淘汰的候选。
3. 继续读右上计划准备状态，再向下进入蓝色全局选择。
4. 沿下方箭头转入橙色操作映射，最后回到左下的执行代码。

## 图形表达

**布局**：左侧窄列分为输入模型、资源与输出代码，右侧按顺时针流程组织四色功能区域。

**对象**：叠片表示多个候选，散点平面表示双指标筛选，短条和小格表示状态与资源占用，操作块连接代码。

**连线**：黑色箭头串接功能区域；内部小箭头表示数据移动或状态转换，不能与全局流程混淆。

**配色**：绿色表示候选生成，红色表示局部权衡，蓝色表示准备与全局协调，橙色表示操作映射；绿星红点只在筛选小图中表达保留与淘汰。

**文字**：模块名无衬线加粗，代码使用等宽字；密集小图需维持层级，适合通栏展示。

## 部件与复用

| 部件 | 含义 | 改造方法 |
|---|---|---|
| 问题、资源与产物 (`inputs-output`) | 给出结构输入、硬件条件与生成代码三类对象。 | 替换成当前任务的约束与真实产物，不把输入输出混接。 |
| 候选计划组 (`plans`) | 按局部计算单元组织多个可执行安排。 | 写清一个计划包含什么决策，叠片数量仅表示存在多个候选。 |
| 局部权衡筛选 (`local-tradeoff`) | 在时间与资源等两个维度筛选候选。 | 坐标轴、点位置和优劣方向全部按实际指标重画。 |
| 计划准备状态 (`plan-state`) | 显示空闲、配置和活动之间的变化。 | 保留真实切换开销与依赖，不能把状态条当作测量记录。 |
| 操作映射 (`code-mapping`) | 将选中计划变成分配、计算及搬移等基本动作。 | 按实际执行接口重写操作与伪代码。 |
| 全局计划选择 (`global-selection`) | 联合考虑多计划的时间、空间占用和切换。 | 全局目标须不同于简单重复局部筛选，并明确跨任务约束。 |

## 改造步骤

1. 列出局部决策与全局约束，明确两次选择各解决什么。
2. 示意散点与曲线需标注，不能暗示已有实测最优点。
3. 对照状态变化重画资源占用条，检查空闲与活动是否冲突。
4. 把左下代码改成真实接口或明确的伪代码，移除章节编号。

## 新情景示例（假设）

可用于车间排产中工序候选、单机权衡与全局排程。

绿色生成工序路线，红色比较时间与成本，蓝色统筹设备占用及换线，橙色生成执行指令。

重绘散点和机器日程，加入工序先后约束，把内存条换成设备占用条。这是适配示例，不声称排程已验证。

## 编辑入口

**入口**：以 make_figure.py 为入口，example.json 存修改参数；labels.json 定位文字键，asset.json 定位部件。运行后查看整图和独立部件。

**配置可改**：labels 改文字及字体；components 改显示、dx/dy 和属性；elements 改对象属性。位移采用整图 viewBox 单位，父子部件重叠时只选一个层级移动。

**需改代码**：迁移必须改 customize() 中候选小图、状态条、曲线与操作列表；参数改标题不足以形成新算法，新增元素要登记部件。

**字体**：正文为 Arimo Regular/Bold/Italic，代码为 Inconsolata Regular；不要用比例字体替代代码导致缩进错位。 font_size 是元素局部单位，受变换影响，不等于纸面字号。

准备独立工作副本：

```text
python "<SKILL>/scripts/prepare_architecture.py" --id VA-103 --out figures/architecture
```

在工作副本运行：

```text
python make_figure.py --config example.json --out . --parts
python render_architecture.py fig.svg
```

## 本图检查

- 局部保留候选是否实际进入后续全局选择。
- 状态条与全局占用条是否使用同一资源口径。
- 顺时针主流程是否因小图内部箭头而被误读。

部件图用于复用局部对象；跨边界的连接和共享容器仍需按新关系处理。示例名称、数值和曲线不是当前研究结果。

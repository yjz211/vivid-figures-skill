# 路径 B：重组构图

你负责 B 候选。先读 [共同制作与验收](../COMMON.md)和分配的 `brief.md`，只在 B 的独立目录工作。主资产、场景与展示宽度由简报确定；不阅读 A 的路径或输出。

**一个视觉基准，按内容组织构图。** 资产提供字体层次、线宽、对象画法和语义配色。原图列数、方向、区域位置、容器数量和连接走廊可以按当前关系重排；可移动、重组、复制适用的原部件，删除没有当前语义的区域。补充局部与主体统一风格，不要求保留原图轮廓。

**复用实际图形，允许重组整图。** 直接复用原 SVG 中适用的图形组合和细节；可拆开原分区，改变排列方向及整体区域比例，重新连接。逐图说明的布局、阅读顺序与几何保留项描述来源设计，不要求照搬原坐标或全部容器。不要清空或遮盖底稿后换成一套通用矩形，也不要只留下旧 ID 来声称复用。

简记采用的部件、需要调整的关系和重组理由。优先继承有用的字体、局部造型和色彩角色；原区域比例与连接组织适合新任务时仍可沿用。不为与 A 不同而强行改变方向、增加装饰或填满空白，也不强制比较两个内部方案。

重组布局不等于删掉图案。原图有图标、对象轮廓或结构示意时，保留适用图形，或自行绘制符合当前语义的 SVG 图案后重新编排；不能将有用的图形表达简化为一排名称或普通文本框。

按共同宽度检查整体和对应主要对象。重排后保持字体角色与层次；避免扩宽画布使全部文字变小，或把粗体/斜体/常规文字统一成一种样式。按共同要求自主修正并交付完整成果，不替协调任务选择最终胜者。

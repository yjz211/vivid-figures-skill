# 路径 A：保留构图

你负责 A 候选。先读 [共同制作与验收](../COMMON.md)和分配的 `brief.md`，只在 A 的独立目录工作。主资产、场景与展示宽度由简报确定；不阅读 B 的路径或输出。

**一个主体，按需补充局部。** 以主体资产确定整图布局、阅读路径、区域比例和视觉层级。已有合适表达就直接沿用；缺少必要表达时，可以从其他资产选取局部部件并统一风格。若补充使主次和阅读顺序失衡，调整局部布局。

**保留实际底稿，适配具体局部。** 直接保留并修改原 SVG 中仍适用的图形、文字和连线。禁止清空 SVG、整体隐藏或遮盖后重画；仅留旧 ID、复制配色不能算复用。只为当前任务增删和重绘具体局部，保留有用的区域比例、细节、连线组织、字体层次和语义配色。删除没有当前依据的对象，调整不适用的拓扑；仅替换标签不等于完成结构迁移。

原图布局无法容纳必要关系时，先精简文字、换行、调整相邻空间与局部走线。若仍需更换主体，反馈协调任务共同重新选型；不要为保留原形状遗漏条件、增加虚构流程或把整图改成另一个构图。

原图的图案与象形示意须保留其图形表达作用；对象语义变化时可局部重画符合当前含义的 SVG 图案，保持原有风格与布局角色，不能直接用文字或普通文本框替代。

原图与成图按简报规定的同一宽度核对。保留构图不免除检查：大块空白与拥挤局部、长绕线、贴边箭头、过小文字都需自主修正。按共同要求交付本路径完整成果，不替协调任务选择最终胜者。

# 架构图模块编辑工作台

完整 Vivid 本地工作台提供 `/architecture-editor.html`。从架构图库打开任意资源的详情，点击“打开模块编辑工作台”，会创建独立工作副本；原资产不变。左侧“已保存项目”可以重开已有作品。此页面无需连接大模型。

安装完整工作台的依赖后启动：

```sh
cd workbench
python -m pip install -r requirements-agent.txt
python -m playwright install chromium
python -X utf8 scripts/manage.py agent --open
```

Skill 包中的离线图库只负责参考和源码浏览；交互编辑、持久保存、PDF/PPTX 导出需要完整工作台本地服务。普通 `serve` 数据图服务不包含这些架构 API。

## 操作

- 点击画布或左侧模块选中，拖动整体移动。Shift 点击多选；方向键移动 1 个画布单位，Shift + 方向键移动 10 个单位。也可以输入 ΔX/ΔY 精确移动。
- 切换“单个图元模式”，单独移动文字、形状或连线路径。搜索支持模块名称、对象编号和文字内容。
- 右侧直接替换标签，按 Enter、“应用文字”或移出输入框生效。未修改文字保持原字体和逐字位置；修改多样式文字时采用首段样式，当前仅支持单行替换。
- 一次拖动对应一次撤销。支持撤销/重做、Ctrl+Z/Ctrl+Y、缩放和适合画布。
- “保存版本”生成新版本。跨页面保存有版本冲突保护，拒绝覆盖较新版本，并保留当前页面修改；先下载本地备份，再打开项目比较。备份恢复限当前项目，恢复操作也能撤销。
- 导出先保存未保存修改，再从该明确版本生成 SVG、PNG、PDF 或原生可编辑 PPTX。完整交付包同时包含 SVG、结构说明、编辑记录、PPTX 转换报告和可用字体；Agent 源码生成的作品另包含源码及来源清单。下载链接对应固定版本，不会指向随后编辑的结果。

## 与 Skill、PPT 共用的规则

网页与 PPT 导出共用 `scripts/pptx_runtime/pptx_groups.py` 的模块归属：优先最小明确部件，归属并列的图元保留独立，不重复移动或复制对象。SVG 原画序保持不变；PPT 因遮挡顺序可能将一个语义模块分成数个具名组。

本地服务将基线 SVG、稳定对象编号、模块映射、坐标映射及版本编辑记录保存在 `workbench/workspace/agent/architecture/`；如果配置了 `VIVID_AGENT_HOME`，则保存在其 `architecture/` 子目录。每次导出都从基线重放选定版本，应用位移和文字，不重新生成模板覆盖人工编辑。移动包含局部裁剪框的完整子树时，裁剪框会随内容移动，网页和导出使用同一坐标规则。

Skill 接手已有网页编辑作品时，先读取用户导出的当前 SVG 和结构资料，以其为改造起点；不要只凭原资产编号重建并丢弃网页修改。当前页面可编辑内置资产与[架构 Agent](AGENT.md)生成的项目，尚不支持任意 SVG 导入。Agent 从当前已保存版本继续；发送任务前会保存网页修改，并发保存冲突时保留候选图，不覆盖人工版本。

## 边界与实际检查

连线不会自动重接，也没有路径节点编辑、模块缩放、自动排版或公式编辑器。可以整条移动连线；端点改造仍在 SVG/代码或 PPT 中完成。移出画布会有红色选框提示；移出祖先裁剪范围或修改过长文字，可能造成部分字形被裁掉，此时原生 PPT 导出会指出需修正的对象。任意移动后仍需人工查看连接关系、文字拥挤与遮挡。

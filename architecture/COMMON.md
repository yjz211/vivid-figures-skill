# 架构图共同制作与验收

本文件供架构图生成与续改任务共同使用。读取任务简报，在自己的输出目录工作，不修改 Skill 或源资产。文件型任务已分配 A/B 路径时，再读取对应路径且不读取另一路生成物；网页单候选任务遵循当前宿主的生成、审查与保存流程，不启动 A/B 调度。

新图的保真基线是共同选定的主资产。续改已选候选或用户已有作品时，基线改为本轮开始的当前版本，保留用户已经接受的结构和字体变化；仅做所请修改及必要的连带修复，不因与历史模板不同而改回去。下文的原图对照在续改时也使用此当前版本。

架构候选按本文件自主审图修正，不采用数据图通用检查的三轮上限。每次修正后重新查看受影响图件，质量满足要求即停止；缺失输入或环境能力确实阻止完成时，保留产物并报告具体未完成项，不假称通过。宿主有硬性执行限制时如实说明。

## 准备独立工作副本

使用简报中选定的资产、图内语言、展示宽度与事实；已分配 A/B 的任务使用协调任务共同选定的资产。准备目录须为空；已有工作的续改使用当前图及源码，不再次准备底稿覆盖它。

```text
python "<SKILL>/scripts/prepare_architecture.py" --id <资产ID> --out <本任务输出目录>
```

工具复制运行代码、底稿、配置、说明、字体和许可，并在 `.vivid/template-sources/` 保存源底稿及哈希。阅读所选资源的 `TEMPLATE.md`、实际预览及需要的部件；其原场景不能代替当前任务关系。补充局部与主体统一字体、线宽、对象尺寸、色彩角色和连接方式，简记来源及用途。若主体无法表达必要关系，重新查看和准备更合适的主体，保留旧工作副本；已分配 A/B 的任务须向协调任务说明原因并统一重新选型，不要只给其中一张换主资产。已有作品续改仍以当前版本为底稿。

## SVG 编辑方式

所有目录资源均由 `make_figure.py` 调用 SVG 编辑运行时。历史代码生成器保留作来源与旧工程兼容，不作为新图的默认路线。

**矢量编辑（196套）**：`diagram.svg` 是独立运行底稿，保留可编辑文字和矢量对象；`labels.json` 提供稳定文字键，`geometry.json` 与 `asset.json` 记录对象和语义部件。配置支持文字、配色、部件显隐与位移。增加、删除和重新连接结构，需要在 `make_figure.py` 的 `customize(root, context)` 中操作实际 SVG 元素。长标签不会自动可靠地重排整个图。

逐图 `guide.json` 是本项目重新理解后编写的说明，`TEMPLATE.md` 是同一内容的阅读版。说明覆盖981个语义部件；既有部件预览及运行时部件导出随对应资源提供，原代码模板的96个语义组也已转为SVG对象部件。部件可能包含其他部件，移动时选定一个层级，避免同一对象重复位移。

## 深度改造

已分配 A/B 的任务按对应路径执行构图约束：[A：保留构图](paths/A.md)或[B：重组构图](paths/B.md)，只读取所分配的一条。单候选任务按当前需求组织构图，无需加载两条路径。所有任务共享本文件的语义、字体与源码要求，交付遵循所在宿主流程。直接修改原 SVG 中仍适用的图形，不以保留 ID 或复制颜色冒充实际复用。

**图案与象形示意不能退化为纯文字。** 原图中的设备轮廓、对象图标、输入样例、层叠数据、网络或张量示意等，是图形表达和版面设计的一部分。语义仍适用时保留并适配实际图形；语义改变时，优先用可编辑的 SVG 形状与路径自行绘制符合当前对象的图案，继承原图的线宽、配色、细节程度和视觉占比，再编排进本路径布局。不得为了省事，将这类图案直接删成一个名称、段落或普通文本框；文字用于命名和解释，不能冒充已经完成的图案替换。

局部图案的必要重画属于语义适配，不受“禁止清空底稿后重画整图”的限制；保留仍有用的其他图元，更新替换图案的对象键和部件归属。确实与当前任务无关、会造成误解且无需同类图形表达的图案可以删除，并在复现说明中简记原因；不为凑数量添加无意义装饰，也不捏造数据曲线、实验图像或不存在的结构细节。

颜色表达对象身份或状态。跨区域同一对象须保持一致；不要把具有多角色语义配色的架构图强改成单主色。使用项目顶层色板时，读取 [架构图语义配色](PALETTE.md)，由 AI 根据实际对象填写本图的角色映射，将容器浅色、描边深色、连接和图例对应到同一身份；必要的警告色与中性色可显式保留。196套矢量资源通过 `color_roles` 接口换色，不能假定全库已有自动角色标注。示例中的数字、曲线、公式与对象身份仅用于演示，正式论文中必须对应当前证据或明确标为示意。

矢量部件通过实际对象集合导出，不是位图裁切。跨边界连线和共享容器可能不属于单个部件，组合时重新核对连接。新对象设置唯一 `data-asset-key`，并加入 `context['parts'][部件ID]['element_keys']`，才能进入该部件导出。未归属对象仍可出现在整图；隐藏部件按实际可见内容标记为空。`asset.json` 的部件可用 `exclude_keys` 显式排除落入区域盒的外部连接碎片；键取自本图 `geometry.json`，排除不影响整图。未知键会报错；若改写底稿使对象重新编号，须重新核对这些键。

## 字体与版面

**文字样式与缩放**：保留原文字的样式属性，新增文字从同类原标签继承字体、真实字重、倾斜、字色、透明度和字距。整图等比缩放时，画布、模块、字号及线宽使用同一倍率；SVG 已通过整体变换或显示尺寸缩放时，不再重复调整字号。仅增加留白或新增分区时，保持原有文字与模块的比例。长标签优先精简、换行，再调整局部布局，不得默认缩小字号、调浅字色或横向压缩文字来容纳内容；用户明确要求改变样式时按其要求执行。

字体角色、字重、倾斜与字号层次属于资源设计。矢量底稿使用显式替代字体，可能改变字形和字宽；并非对来源字体的精确复刻。`fonts/source-assets/` 提供所需开放字体，运行时嵌入实际使用的字体。新增文字先确认字符覆盖，实际查看字距、上下标和换行。`font_size` 是元素局部坐标单位，不直接等于纸面字号，不能无视缩放统一设为某个数值。

图内文字遵循任务语言，默认中文。源字体缺少所需字符时，不强留该字体，也不通过改成英文规避；在工作副本中按原衬线、无衬线或等宽角色，选择覆盖实际文字的完整可用字体，并保留对应的真实字重、倾斜和字号层次。检查实际字体文件的字符覆盖与字形，不依赖未记录的系统回退；替换后重新查看字宽、换行、模块比例及同宽文字尺度。字体替换属于必要的语义适配，记录所用字体及交付依赖；VA-001 的角色配置方法见其[字体说明](source-variants/network-inset-svg/FONTS.md)。

VA-001 的系统字体与便携字体见 [字体说明](source-variants/network-inset-svg/FONTS.md)；VA-004 使用系统 Arial，其余资源按各自说明保留字体。替换子集字体时可能改变字宽，切换后重看实际布局；技术可运行不表示视觉上无需调整。

**对象与关系同步**：结构改动后同步部件的成员、文字键和边界；新 key 应唯一且稳定，不用会随删除而回退的树节点数生成 key。重接箭头时同步实际端点和机器可读的起终点语义，移除过期的来源关系。逐条阅读当前任务要求的输入、输出、分支和回路，确认线接到真正承担该关系的对象；背景后面的线、无对象的箭头、意外共用交点都须实际核对。

**保住最终文字尺度**：改造前从原图记录主要文字的实际显示大小、字体/字重/颜色和字框比例；用最终展示宽度与论文宽度再次比对，不只检查 font-size 属性。增加内容后先调整措辞、分组和布局，避免扩宽画布把全部主体和文字一起缩小。部件内部保留合适的文字层级和细节；新增内容从同类对象继承样式。整图和部件导出都应实际查看，自主修正后交付最终版本。

在已有复现说明中简记代表性主模块、容器标题与次级说明的源/成图字体、真实字重、倾斜和同宽大小；不存在的角色无需补造。核对相同角色，不能用全文字平均字号掩盖主模块缩小，也不能用整体放大字体代替恢复粗体、斜体与常规文字的分工。只有同宽展示目标时按该目标比较，不虚构已经进行过论文印刷检查。

## 生成与交付

在准备好的工作副本运行：

```text
python make_figure.py --config example.json --out . --parts
python check_architecture_connections.py fig.svg
python render_architecture.py fig.svg
python "<SKILL>/scripts/review_architecture_source.py" .
```

连线预检查在渲染前用实际文字边界查找语义折线的穿字候选，结果保存在 `fig.connections.json`。先核对报告中的明确冲突并调整局部路线或文字位置；工具不移动图元。它只覆盖带 `data-from` / `data-to` 的直线与折线，须同时阅读覆盖数量、跳过项和遮挡信息；没有受支持连线不代表检查通过。曲线、复杂遮罩及未标注的矢量底稿仍需实际看图。

输出可编辑 SVG、PNG、矢量 PDF、`structure.json` 与 `parts/index.json`。打开实际成图，核对本图说明中的检查项，以及语义、箭头落点、文字交叠、层次、边界和最终论文宽度。渲染器的字号、裁切、交叠和 PDF 字体检测是诊断证据，不能替代实际阅读，也不能通过降低阈值解决视觉问题。导出部件不会自动加入公共资产库。

核对部件索引中的 SVG 确实存在且含所承诺的可见图元和文字；实际查看主要部件，修复空导出、漏字及重复对象键。新增连线的起终点标注须能解析到当前对象；未标注或被检测器跳过的连线仍逐条看图。记录实际用于最终生成的入口和复现命令，不能把未调用的旧 `make_figure.py` 冒充入口。

对照原图检查主要图案在成图中是保留、语义重绘还是有理由删除；仍需要图形表达却只剩文字、空框或标签的，验收不通过，须自行补画并重看布局。新画图案也须进入真实 SVG 部件及后续可编辑 PPT，不能只在 PNG 预览中补上。

在本候选的复现说明中写明实际复现命令、代表性字体核对和未解决问题；将执行所需源码、配置和依赖说明随图保留。已分配 A/B 的任务在 `README.md` 中另记所用路径，返回交付路径与完成状态，由协调任务汇总对照，不自行重开 A/B 调度。网页单候选任务将实际 SVG、部件结构和源码导入当前工作台并按宿主流程保存。

**视觉保真对照**：在现有看图验收中，将主体模板原图与成图按相同展示宽度并排查看，对照文字的实际大小、字重与字色、模块比例、线宽、色彩对比、留白及视觉重点；仅增加留白或分区时，同时对照对应模块的文字比例。区分任务必需的结构适配与非必要的风格改动，修正无必要的主体缩小、层次减弱或布局松散；主要文字无必要地变小、变细或变浅时，保真验收不通过，须修正，不以无交叠、无越界代替保真通过。

文件型 A/B 任务在候选阶段先准备完整 SVG/PDF/PNG 与部件，交给协调任务向用户展示 A/B；暂不为未选中的图生成 PPT。用户选择后，协调任务按 [可编辑 PPTX 导出](PPTX.md) 直接交付所选版本的原生 PPTX、SVG 与 PDF，附字体包并验证。网页单候选任务保存至当前画布，用户按需通过工作台导出。PPT 中移动部件不会自动重新连接箭头，人工修改也不自动回写 SVG。

已有6个[假设情景迁移示例](migration-examples/index.html)，用于展示改造范围，不是实证结果，也不证明其余资源均已迁移验证。用户尚未审阅时只报告技术检查与具体视觉发现。

必要来源与权利记录集中在 [ATTRIBUTION.md](ATTRIBUTION.md) 和各资产同名文件；字体遵守附带许可。派生几何不会因重新编写说明而变为从零原创。

## 网页中继续编辑

用户选中候选后需要手动调整时，完整工作台提供[模块编辑器](EDITOR.md)。网页与原生 PPT 复用同一模块归属；导出前保存当前版本。Skill 后续改图以当前作品为起点，保留人工位移和文字。完整工作台的[架构 Agent](AGENT.md)使用本 Skill 真实流程及同一检索器，可准备主体/补充源码、修改生成代码、执行并审图，再将 SVG＋具名部件导入编辑器。简单调整仍可直接用图元接口，完整设计不受这些局部接口限制。

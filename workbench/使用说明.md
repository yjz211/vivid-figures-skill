# Vivid 绘图工作台

本地选图、修改数据和出图。147 个模板（144 个单图配方＋3 个完整组合）均可编辑，不需要接入大模型。

## 开始使用

1. 双击本文件夹里的 **启动工作台.cmd**。
2. 浏览器打开 **http://127.0.0.1:8766/index.html**。
3. 搜索或按分类找到图，点击 **修改数据，使用此模板**。
4. 修改表格或导入 CSV / TSV / XLSX，核对右侧字段对应，再点击 **更新预览**。
5. 预览成功后，点击 **导出** 获取 PNG、PDF、SVG、数据或完整源码复现包。

只想找图、看样式和取原始模板包，也可直接双击 `index.html`。修改数据后重新绘图需要启动本地 Python 服务。

## 找到合适的图

- 分类、中文图名、英文别名、卡片关键词、数据特征和用途均可检索。
- 多个搜索词用空格隔开；点卡片查看大图、适用数据和视觉要点。
- 图表库预览统一使用粉彩少女。编辑器支持现有 7 套配色。
- 收藏保存在当前浏览器；`/` 聚焦搜索，`Esc` 关闭详情。

## 编辑器布局

- 左侧 **项目** 列出当前图的数据表和图表；点击数据表会切换底部表格，并打开右侧字段对应。
- 中央是画布。底部为数据表，拖动两者之间的分隔条调整高度；选中分隔条后也可用上下方向键调整。数据面板、项目栏和设置面板可以分别收起。
- 右侧有 **图形 / 数据 / 对象** 三个页签。默认显示整张图的设置；点击图内对象切换到它的属性，点击画布空白或按 Esc 回到图形设置。
- 撤销、重做在顶部。数据表右上角提供导入、整理数据、对应字段；示例下载、恢复示例、清空选区和删除行在 **更多操作 / 格式要求** 中。
- 当前项目仍对应一张模板图（可以包含原有组合子图）；自由组合图与一份数据关联多张图尚未加入。

## 编辑数据

- 单击选择，双击或 Enter 编辑；方向键移动，Shift 扩大选区，Ctrl+C / Ctrl+V 复制粘贴，Delete 清空选区。撤销为 Ctrl+Z，重做为 Ctrl+Shift+Z。
- 单击行号或列头选择整行、整列。双击列头修改列名，拖动列边界调整宽度；右键菜单可删除行列。
- 表格使用连续滚动。单表最多 20000 行、256 列、500000 个单元格；具体模板可能有更严格的数据要求。
- 粘贴默认从选区左上角覆盖并按需扩展。选择“精确覆盖选区”时，行列数必须完全一致，不自动重复填充或截断。勾选“首行为表头”后会更新对应列名。
- 多表模板在左侧项目栏或底部 **数据表** 下拉框切换。例如 SHAP 图需要特征值和对应 SHAP 值；网络图可能同时需要节点、边和路径。
- **导入** 只替换当前选中的数据表，不覆盖其他表。Excel 文件可以选择工作表。导入后按唯一列名保留已有字段对应，无法确认时显示未对应，避免文件列顺序改变后误用数据。
- **示例** 下载当前数据表的 CSV，先按这个格式填数最方便。
- 固定字段表可以在右侧重新对应导入文件的列；矩阵表通常第一列为行标签，后续列为数值。曲面网格的行、列标签有时是实际 Y、X 坐标，以数据表名称和提示为准。
- 右侧字段标签可以拖到对应下拉框；点击“建议对应”可按列名匹配；基础模板还会参考列类型。含义不明确或重名的字段仍需手动指定，数值系列建议会排除常见误差列。
- 校验失败会提示原因；单元格错误会定位到对应行列。关联表的样本、标签、顺序和尺寸需要匹配。

首次打开的数值是演示数据。真实分析请逐张替换相关输入表，尤其是置信区间、检验结果、模型输出等表。

### 整理数据

点击表格右上角 **整理数据**，选择操作与列，先 **预览处理结果**，核对后再 **应用到当前表**。关闭窗口不会修改数据。应用后可用顶部撤销/重做恢复，之后点击更新预览出图。

| 操作 | 用法 |
| --- | --- |
| 排序 | 按一列升序或降序；数字按数值排序，空值置于末尾 |
| 筛选保留行 | 按相等、包含文字、数值大小或空值条件保留行 |
| 行列转置 | 第一列变为表头，原数值列表头变为第一列；行标签须非空且唯一 |
| 宽表 → 长表 | 保留一个标识列，把指定的多个数值列展开为“标识、系列、数值” |
| 长表 → 宽表 | 选择行标识、系列和数值列，展开为每系列一列；重复组合需先明确汇总方式，缺失组合留空 |
| 分组汇总 | 明确选择均值、样本标准差、合计或有效数值个数；不自动决定统计口径 |

预览最多显示 8 行、12 列，实际处理完整数据。操作只改变当前数据表，关联表需自行保持一致。转置、展开或汇总后请重新核对字段对应。整理过程不插值、不补零，不把空白当作数值；分组汇总遇到空白或非数字会提示处理，样本标准差要求每组至少两个数值，分母为 n−1。

## 调整图形

可修改标题、轴名称、配色、尺寸、字号、图例和数据标注。三维模板默认保留原版视角，修改俯仰角或方位角可切换自定义视角。部分模板另有径向上限、山脊间距、数值后缀等设置。

切换配色会自动调用原模板重绘，无需点击更新按钮。连续切换会合并请求，正在运行的旧配色结果不会覆盖最新选择；Python 生成图片仍需要短暂时间，顶部状态显示进度。

图形来自现有完整 Python 源码。接入代码替换数据入口、适配数组尺寸和必要的统计计算，保留各模板的绘图结构。

### 直接选择图形对象

Matplotlib 图生成后默认进入交互编辑。悬停会出现虚线高亮和对象名称，点选后显示文字选框和画布上方的单行工具栏；也可以使用右侧 **对象** 页签中的 **图形对象** 下拉框选择。点击 **返回导出预览** 可查看不带交互控件的图片，再点 **交互编辑** 返回。

坐标轴仅沿轴线附近响应，三维轴面和网格不响应点选。小标签优先按文字边界识别，字形与字间空隙使用同一规则。单行工具栏仅在明确选中后显示编辑控件，固定在画布上方，不覆盖图内文字；点击空白处、工具栏 × 或按 Esc 可取消选择。

- 标题、轴名称、刻度文字、数值标签和普通标注可以直接拖动。拖动时实时预览位置，松手后自动保存并重绘；工具条可修改文字、字号、颜色或复位位置。
- 拖动时按住 Shift 锁定水平/垂直方向；Esc 取消当前拖动。选中文字后，方向键微调 1 pt，Shift＋方向键微调 10 pt。Ctrl+Z / Ctrl+Shift+Z 撤销和重做。
- 偏移以物理单位 pt 保存，向右、向下为正，随项目进入 PNG/PDF/SVG 和源码复现。三维数据标签沿当前画面平面移动；数据坐标不变。箭头标注保留原数据锚点。
- 数据或全局设置变化后，要等新图生成才能继续拖动。标签的位置不包含在“我的样式”里，避免把一张图的位置搬到另一张图。
- 此次文字拖动适用于 Matplotlib 模板；Plotly 模板继续使用原生旋转/缩放和右侧属性编辑。

- 文字可修改内容、字号、颜色、旋转和显示状态；轴可修改名称、范围与刻度文字。范围按起点、终点表示，保留热图的反向坐标。色标仅开放文字属性，避免把色标轴范围误当成数据颜色范围。
- Matplotlib 图例可修改位置、列数、字号和边框；有名称的原生折线可修改颜色、线宽和透明度。部分复杂填充、曲面和组合元素目前仅开放其轴、文字和图例。
- 对象修改可以撤销，并自动更新图片。**还原此对象** 只清除它的修改；**恢复模板样式** 清除全部对象修改和自定义视角。重绘完成前导出不可用，保证文件对应当前状态。
- 对象修改优先于全局文字设置。若需要统一全局控制，可先还原对应对象。
- 改变行数、列名、分类或字段绑定后，旧对象修改会保留记录但不再自动套用；提示中列出失效数量，可点击 **清理失效修改** 后重新设置。普通数值变化通常保留对象修改。

### 三维交互和样式复用

已有 Plotly 模板会显示 **三维交互 / 缩放** 按钮，支持原生悬浮、旋转和缩放。相机及数值坐标范围自动记录到项目，可撤销；随后点击 **更新预览**，图片导出与新视角一致。**返回导出预览** 显示上次已生成的静态图。Matplotlib 三维图继续通过俯仰角和方位角调整。

**我的样式** 保存配色、字号、尺寸和图例/标注开关。跨模板应用通用外观；同模板、同数据结构时还应用兼容的对象外观。数据、文字内容和坐标范围保持当前值。

### 数据量与示例不同时

示例行数不是固定要求。可增减样本、分类和数值系列，具体范围见数据面板的 **数据格式与数量要求**。方阵需同步增减两个方向，多表模板需同步维护相关样本、指标或类别。例如新增 SHAP 特征时，特征表、SHAP 表及特征分组表都需要相应更新。

部分分类图提供 **数据增多时自动扩展画布**；手动指定最终尺寸时可取消此项。长折线保留全部数据点，并减少横轴文字刻度密度。三维分组柱支持 1–10 行、1–12 个数值系列；超过 40 根柱时可自动避让重叠数值标注，全部柱仍保留。可在专属设置中关闭避让。

多 Y 轴渐变直方图沿用原模板的 1–3 组范围，每组对应独立 Y 轴。固定组合布局及分析结构的要求仍然适用。

删除已对应的数据列后，需要重新选择该字段；工作台会显示未对应状态，避免把相邻列误当作原字段。撤销可恢复该列及对应关系。

改过数据或设置后，当前图片会标为旧结果，导出暂时禁用。点击 **更新预览** 后再导出，避免把旧图当成新结果。

## 保存、导出与复现

- **保存项目**：下载 `.vivid.json`，包含所有数据表、字段对应与设置。
- **打开项目**：恢复项目；点击更新预览重新生成图片。
- 修改会自动保存到本机 `workspace/library/projects/`，重新打开编辑器会恢复最近草稿；右上角 **最近项目** 可以打开历史项目或将当前项目存为独立副本。下载项目文件可用于备份或迁移。
- **PNG**：高分辨率输出；Matplotlib 图为 300 DPI。
- **PDF / SVG**：保留渲染器支持的矢量元素；Plotly 三维图会在文件中嵌入栅格图层。
- **当前数据表 CSV**：仅当前表；完整复现包的 `tables/` 包含全部输入表。
- **绘图源码**：`plot.py` 是本次完整适配结果，需配合复现包中的数据与辅助模块。
- **完整复现包**：包含原始源码、适配源码、数据、设置、差异记录、绘图引擎、依赖清单与运行入口。
- 对象修改保存在 `project.json` 的 `object_edits`，交互视角保存在 `plotly_view`；`object_editor.py` 在完整模板绘制后回放修改。`objects.json` 记录对象属性及失效项，所有文件都随复现包导出。

解压复现包，在解压目录执行：

```powershell
python -m pip install -r requirements.txt
python run.py
```

`run.py` 读取 `project.json`，重新生成 `plot.py` 和图片。若想继续修改绘图主体，请编辑包内 `source.py` 对应段落；单独修改 `plot.py` 会在重新运行时被覆盖。

Plotly 静态导出需要本机 Chrome / Chromium。中文图建议安装微软雅黑或其他中文字体。

## 统计数据的口径

- ROC、校准、相关系数、聚类诊断等使用实际输入计算；不保留演示 AUC、固定 p 值或随机误差。
- 模板需要区间、标准误、SHAP 值、PCA 得分、预测结果、合并估计时，需提供实际分析输出。工作台不会从任意表格推断这些结果。
- 生存图支持两组随访时间及右删失；使用 Kaplan–Meier 曲线、Greenwood 近似区间和 log-rank 检验。
- 热图使用原有配色规则；分档热图中，同档内的小幅数值变化可能不会改变色块。
- 省级地图使用随包提供的中国省级底图，按完整省名匹配。其他区域底图需要另行适配。
- 图像重建对比目前输入灰度矩阵；体绘制输入三维采样表。固定组合布局的数据组数以模板提示为准。
- SEM 小提琴组合输入各构念的计分结果，绘制逐变量回归残差与 Pearson 矩阵；这里的残差不等于拟合完整 SEM 模型后的残差。

## 操作流程改进

- **手动字段绑定：**导入数据 → 搜索模板 →「用我的数据」→ 选表、对应字段 → 生成新图，全程不要求模型。多表模板可分别选择输入。
- **助手操作范围：**明确区分新建图和修改当前图，并提供数据表选择；新图不会覆盖当前图，只改样式时保留原数据和手动位置。
- **画布空间：**数据与属性面板默认折叠，窄屏默认收起助手；对象编辑条放在图外，选中文字不会迫使面板展开并挤动画布。
- **直接编辑：**点选、拖动、取消选择与快速换色可连贯使用。历史版本可查看实际图片，审图消息标明当时的版本。
- **工作区隔离：**切换期间锁定旧交互，晚返回的请求不能替换新工作区的图或任务；保存失败时保留较新的未保存修改。切换失败保留原图。
- **Excel 选表：**先列出工作表，再读取选中表；封面页不是有效数据表时，也能选择后面的数据页。

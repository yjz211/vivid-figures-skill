# Vivid 绘图工作台

本地选图、导入数据、调整图形并导出。148 个模板（145 个单图配方和 3 套组合）均可编辑，支持 7 套配色；图库统一使用粉彩少女预览，无需接入大模型。

新增[环形分组对比柱状图](../catalog/cards/advanced.grouped_radial_bar.md)，按参考图复刻任务内多系列、组间留白和外围层级弧线，展示使用粉彩少女配色。柱长按每个任务的组内最小值与最大值独立缩放，仅在同一任务内可比；数值标签保留原值。

## 开始使用

**Agent 工作台**使用同一套模板和可拖动编辑器。可以手动选择数据和字段直接出图，也可以让助手选图、整理数据、修改和检查图片。详细操作、开源复用和启动方式见 [Agent 工作台](docs/AGENT-WORKBENCH.md)，本轮实测范围见 [质量报告](docs/AGENT-QUALITY-REPORT.md)。常规手动编辑器仍可独立启动。

Agent 入口：在 `workbench` 目录安装 `requirements-agent.txt` 后执行 `python -X utf8 scripts/manage.py agent --open`，或双击 `启动Agent工作台.cmd`。地址为 <http://127.0.0.1:8766/agent.html>。手动绘图不需要模型；使用助手时优先连接本机已登录的 Codex CLI，也支持配置兼容 API。Agent 数据整理需要 Node.js。

安装 Python 3.11 或更新版本，在仓库根目录执行：

```sh
cd workbench
python -m pip install -r requirements.txt
python -X utf8 scripts/manage.py serve --open
```

浏览器打开 <http://127.0.0.1:8766/index.html>。Windows 安装依赖后也可双击 `启动工作台.cmd`；启动器优先使用工作台的 `.venv`，随后查找 `py` 或 `python`。服务运行期间保留启动窗口。

只看图库和下载原始模板包时，可直接用浏览器打开 `index.html`。编辑数据和生成新图需要本地 Python 服务。Plotly 静态导出需要 Chrome / Chromium，中文图需要中文字体。

## 使用流程

### Agent 工作台

1. 导入 CSV、TSV 或 XLSX；Excel 先列出工作表，再读取所选表，首张封面或说明页不会阻止选择其他表。
2. **手动出图：**搜索模板，点击「用我的数据」，选择数据表、对应标签与数值列，确认配色后「生成新图」。多表模板分别对应各部分输入，全程无需模型。
3. **助手出图：**在对话框上方选择「新建一张图」或「修改当前图」，并选择数据表，再输入要求。新建会保留已有图；修改当前图默认沿用其数据。
4. 数据和属性面板默认收起，按需打开。点选 Matplotlib 图中文字后可直接拖动，画布上方可改文字和配色；「×」可取消当前对象选择。配色变更会重新渲染，并保留手动位置。
5. 「版本」可查看当时的图片、恢复或另存新图；「导出」可下载图片、数据、源码和完整复现包。

较窄的窗口默认收起助手，更窄时同时收起工作区，顶部按钮可重新展开。图表切换和工作区切换会保护尚未保存的编辑，模型执行期间也可继续手动修改；遇到版本冲突时保留双方结果。

### 常规手动编辑器

1. 按分类或关键词找到模板，查看预览和适用数据。
2. 点击「修改数据，使用此模板」，导入 CSV、TSV、XLSX，或直接编辑表格。
3. 核对字段对应和数据格式，更新预览；可切换配色、调整属性，点选和拖动 Matplotlib 图中文字。
4. 导出 PNG、PDF、SVG、CSV、绘图源码或完整复现包；保存项目以便继续编辑。

支持排序、筛选、转置、长宽表转换、分组汇总、多表输入、撤销重做、本地项目与样式保存。需要统计分析结果的模板仍需用户提供相应输入；具体限制见 [使用说明](使用说明.md)。

## 文件位置

| 目录 | 内容 |
| --- | --- |
| `frontend/` | 前端界面、表格、对象交互和样式 |
| `editor_backend/` | Python 服务、数据契约、完整模板源码适配和运行工具 |
| `assets/` | 148 个模板的源码、卡片、预览、下载包和前端依赖 |
| `scripts/`、`tests/` | 维护入口与回归测试 |
| `docs/` | 维护说明、模板来源快照和交互调研 |
| `workspace/` | 运行时创建的用户项目、样式和绘图任务，不进入 Git |
| `verification/` | 运行测试后生成的验证产物，不进入 Git |

工作台随本仓库维护，使用自带模板快照。Skill 入口仍是仓库根目录的 `SKILL.md`；使用工作台无需安装 Skill。

维护方法见 [维护说明](docs/MAINTENANCE.md)，使用许可见仓库 [LICENSE](../LICENSE)。

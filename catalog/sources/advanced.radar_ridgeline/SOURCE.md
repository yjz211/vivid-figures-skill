# 雷达山脊融合图：来源、编码与调用

[参考图](reference.jpg) · [当前完整源码](original.py)

用途：在同一极坐标中比较多个数据层在一组有序指标上的相对高低，并以环形局部峰增强轮廓辨识。

输入：宽表首列为 5–16 个唯一指标，后接 2–4 个同尺度数据层。所有数值必须有限；成本型指标应先统一高低优方向。峰高使用全部数据的共同最小值和最大值归一化，因此不同环之间可比较相对高度。

结构：固定径向虚线作为雷达骨架；每个数据层占一个独立基准圆环；每个指标方向叠加局部高斯峰，填充、轮廓线、基准圆和峰顶数值同时保留；最外圈放指标名，图例置于右侧。

统计含义：这里的“山脊”是标量轮廓编码，不是根据原始样本计算的 KDE，也不表示概率密度、样本量或不确定性。局部峰宽固定，仅用于形成连续轮廓；只有峰高和文字数值承载数据。

配色：数据层颜色读取当前 Vivid 项目配色，固定透明填充并保留同色轮廓；换色不改变透明度、圆环结构或文字层级。

来源：用户只提供效果图，没有原始代码和数据。本实现按图重建可见结构，演示数值为人工构造，仅用于检查布局，不代表实测结论。

## 调用

在初始化的 Vivid 工作区运行：

```text
python original.py
python original.py --data scores.csv --output figures/fig_scores
python original.py --data scores.csv --suffix "" --format .2f
```

CSV 示例：

```csv
category,方案甲,方案乙,总体
精度,32.8,38.6,44.7
效率,25.4,31.1,36.2
```

Python 接口：`plot_chart(categories, layer_names, values, value_suffix='%', value_format='.1f')`。`values` 形状为“数据层×指标”。依赖 NumPy、Matplotlib 和随包 Vivid 工具。
